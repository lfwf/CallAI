# CALL//AI 编辑与核验规范

CALL//AI 的目标不是搬运活动，而是建立可核验、可检索、可持续更新的 AI 赛事与活动情报库。

## 收录边界

优先收录：

- AI 算法竞赛、黑客松、学术评测与开源挑战
- AI 影像、音乐、设计、广告和艺术创作赛事
- AI 创业大赛、Demo Day、训练营和重要社区活动

普通课程促销、无明确主办方的群聊活动、无法找到官方页面的二手信息不进入正式活动库。

## 来源原则

1. 二手平台只用于发现线索。
2. 正式入库必须存在可访问的官方页面或官方主办平台页面。
3. 奖金、资格、日期、版权和提交要求不得根据宣传文案自行推断。
4. 信息存在冲突时，保留冲突说明并标记为 `partial` 或 `pending`。

推荐字段：

```json
{
  "sourceLevel": "official",
  "confidence": "verified",
  "audience": ["独立开发者", "学生团队"],
  "benefits": ["现金奖金", "产品曝光"],
  "risks": ["必须使用指定 API"],
  "difficulty": "intermediate",
  "effortHours": 40,
  "score": {
    "credibility": 5,
    "reward": 4,
    "industryValue": 5,
    "beginnerFriendly": 2,
    "timeCost": 3
  }
}
```

这些字段当前为渐进式增强字段，不要求历史活动一次性补齐。

## 编辑流程

```text
来源扫描
→ 发现候选活动
→ 查找官方页面
→ 提取结构化字段
→ 冲突与重复检查
→ 人工核验
→ 发布
→ 截止前复核
→ 结果跟踪
```

## 状态定义

- `verified`：关键字段已从官方页面核验。
- `partial`：官方页面存在，但部分字段未公布或存在冲突。
- `pending`：仅作为编辑队列，不应作为重点推荐。

## 推荐判断

每场活动至少回答：

- 适合谁
- 需要什么能力
- 预计投入多少时间
- 最大收益是什么
- 主要风险是什么

评分不得替代事实。推荐内容必须能追溯到官方规则或清楚标注为编辑判断。

## 更新频率

- 高优先级来源：每 12 小时检查一次
- 中优先级来源：每 24 小时检查一次
- 活动截止前 7 天：至少重新核验一次
- 已结束活动：继续补充结果、获奖名单和优秀作品链接

## 质量指标

- 官方来源覆盖率
- 字段完整率
- 超过 14 天未核验活动数
- 未来 7 天截止活动数
- 链接失效率
- 从官方发布到收录的平均延迟
